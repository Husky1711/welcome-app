# GitHub Pages — Privacy Policy

## Public URL (after enabling Pages)

```
https://husky1711.github.io/welcome-app/
```

Alternate direct link:

```
https://husky1711.github.io/welcome-app/privacy-policy.html
```

Use either URL in Google Play Console **Privacy policy** field.

## One-time setup (2 minutes)

1. Open [github.com/Husky1711/welcome-app/settings/pages](https://github.com/Husky1711/welcome-app/settings/pages)
2. **Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **`main`**
   - Folder: **`/docs`**
3. Click **Save**
4. Wait 1–3 minutes for the site to deploy
5. Open `https://husky1711.github.io/welcome-app/` to verify

## Files served

| File | Purpose |
|------|---------|
| `docs/index.html` | Main privacy policy (root URL) |
| `docs/privacy-policy.html` | Same policy, alternate path |
| `docs/.nojekyll` | Ensures GitHub Pages serves static HTML correctly |
